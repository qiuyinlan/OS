# OCW (Operational Command Word)

**OCW**，全称为**操作命令字**（Operational Command Word），是在[[可编程中断控制器 (PIC) 8259A]]完成初始化后，用于在运行时动态控制其行为的命令。

## 核心作用
在[[可编程中断控制器 (PIC) 8259A|PIC]]被[[ICW|ICW]]初始化并进入正常工作状态后，[[中央处理器 (CPU)]]可以通过向其端口发送OCW来执行各种控制操作，而无需重新初始化。

## OCW的种类
共有三种操作命令字，OCW1, OCW2, 和 OCW3。

### OCW1: 中断屏蔽
- **作用**: 设置**中断屏蔽寄存器**（Interrupt Mask Register, IMR）。
- **功能**: 允许或禁止[[可编程中断控制器 (PIC) 8259A|PIC]]接收来自特定[[IRQ]]线上的[[中断]]请求。
- **机制**: IMR是一个8位[[寄存器]]，每一位对应一条[[IRQ]]线（`D0`对应`IRQ0`，`D7`对应`IRQ7`）。
    -   如果某位被设为`1`，则对应的[[IRQ]]线被**屏蔽**（忽略）。
    -   如果某位被设为`0`，则对应的[[IRQ]]线被**允许**。

### OCW2: 中断结束与优先级控制
- **作用**: 主要用于发送**[[EOI (End of Interrupt)|EOI]]（中断结束）**命令，并可以控制[[中断]]的优先级轮转方式。
- **EOI功能**: 当一个[[中断处理程序]]执行完毕后，必须发送OCW2来通知PIC，以便PIC可以处理下一个[[中断]]。

### OCW3: 状态读取与特殊屏蔽
- **作用**: 用于读取PIC的内部状态[[寄存器]]，或设置特殊的屏蔽模式。
- **状态读取**: 允许[[中央处理器 (CPU)]]查询**中断请求寄存器**（Interrupt Request Register, IRR）和**服务中寄存器**（In-Service Register, ISR），以了解哪些[[中断]]正在请求，哪些[[中断]]正在被服务。
- **特殊屏蔽模式 (Special Mask Mode)**: 在某些场景下，可以实现更灵活的[[中断]]屏蔽策略。
