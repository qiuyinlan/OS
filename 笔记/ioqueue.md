# ioqueue (I/O Queue)

`ioqueue` 是在《操作系统真相还原》项目中实现的一个**环形缓冲区**（Circular Buffer）数据结构。它的主要目的是解决[[生产者与消费者问题]]，特别是在处理来自[[键盘]]等设备的异步输入时。

## 核心作用
- **缓冲数据**: 作为一个缓冲区，`ioqueue`用于暂存由“生产者”（如[[键盘中断处理程序]]）产生的数据。
- **解耦生产者和消费者**: 它允许生产者和消费者以不同的速率工作。例如，用户快速地敲击[[键盘]]，而[[Shell]]进程在稍后才处理这些输入。
- **实现同步与互斥**: 通过内置的[[锁]]机制，`ioqueue`确保了在任何时刻只有一个任务（生产者或消费者）可以操作缓冲区，避免了[[竞争条件]]。

## 数据结构 (`struct ioqueue`)
一个`ioqueue`结构体通常包含以下成员：
- **`buf`**: 用于存储数据的数组。
- **`head`** 和 **`tail`**: 两个指针，分别指向缓冲区的头部（用于写入）和尾部（用于读取）。当指针到达数组末尾时，它们会通过取模运算回到数组的开头，形成一个“环”。
- **`lock`**: 一个[[锁 (Lock)]]，用于保证对缓冲区的[[互斥 (Mutual Exclusion)]]访问。
- **`producer`** 和 **`consumer`**: 两个[[线程 (Thread)]]指针，分别记录因缓冲区满而[[阻塞]]的生产者和因缓冲区空而[[阻塞]]的消费者。

## 主要操作
- **`ioq_putchar()` (生产者操作)**:
    1.  获取`lock`以保证[[互斥 (Mutual Exclusion)]]。
    2.  检查缓冲区是否已满。如果已满，则将当前生产者[[线程 (Thread)]]的状态设为[[阻塞]]，并将其加入`producer`等待队列。
    3.  将[[数据]]写入`buf[head]`，并更新`head`指针。
    4.  如果`consumer`队列中有正在等待的消费者，唤醒它。
    5.  释放`lock`。
- **`ioq_getchar()` (消费者操作)**:
    1.  获取`lock`。
    2.  检查缓冲区是否为空。如果为空，则将当前消费者[[线程 (Thread)]]的状态设为[[阻塞]]，并将其加入`consumer`等待队列。
    3.  从`buf[tail]`读取[[数据]]，并更新`tail`指针。
    4.  如果`producer`队列中有正在等待的生产者，唤醒它。
    5.  释放`lock`。
