# MBR引导程序

**MBR引导程序**（MBR Bootloader）是存放在[[MBR主引导记录]]最开头的一小段（小于446字节）可执行的[[机器语言]][[代码]]。它是计算机从[[BIOS]]交接控制权后，执行的第一段来自[[硬盘]]的[[程序]]。

## 核心作用
1.  **寻找活动分区**: MBR引导程序的主要任务是扫描位于其后的[[DPT (磁盘分区表)]]，找到被标记为“活动”（Bootable）的那个[[分区]]。
2.  **加载并移交控制权**: 找到活动分区后，它会将该分区的第一个扇区（即[[OBR (操作系统引导记录)]]）加载到[[内存]]中的一个约定俗成的地址（通常是`0x7C00`，此时原来的MBR[[代码]]就被覆盖了），然后通过一个`jmp`[[指令]]，将[[中央处理器 (CPU)]]的控制权移交给OBR。

## 执行流程
`BIOS` → `加载MBR到0x7C00并跳转` → `执行MBR引导程序` → `MBR引导程序加载OBR到0x7C00` → `跳转到0x7C00执行OBR`

## 限制与特点
- **空间极小**: 由于[[DPT (磁盘分区表)]]和结束标志占用了[[MBR主引导记录]]扇区的一部分空间，留给引导程序的[[代码]]空间非常小，通常只有440字节左右。
- **功能单一**: 因为空间限制，MBR引导程序的功能通常非常简单，只负责找到下一个引导阶段的[[代码]]（即OBR）并加载它，不具备识别[[文件系统]]等复杂功能。
- **与硬件紧密相关**: 这段[[代码]]直接由[[中央处理器 (CPU)]]在16位的[[实模式]]下执行，需要直接操作[[硬件]]来完成磁盘读取等任务。
