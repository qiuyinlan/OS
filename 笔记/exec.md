# exec

`exec` 是 [[UNIX]] 系统调用家族的总称（包括`execv`, `execl`, `execve`等），其核心功能是**用一个全新的程序替换当前进程的映像**。

## 核心行为
- **替换进程**: `exec`调用会从磁盘加载一个新的可执行文件（如[[ELF]]格式文件），并用它的代码段、数据段、堆和栈来完全替换当前进程的内存空间。
- **PID不变**: 进程的`pid`在`exec`调用后保持不变。`exec`并没有创建新进程，只是用新程序“覆盖”了老程序。
- **无返回**: 如果`exec`调用成功，它将永远不会返回到调用它的源程序，因为源程序的代码和数据已经被新程序覆盖了。如果`exec`调用失败（例如，文件不存在或格式错误），它会返回`-1`。

## `fork` 与 `exec` 的组合
在UNIX/Linux中，创建新进程并运行一个新程序的标准方式是 `fork()` 后跟 `exec()`。
1.  **`fork()`**: 父进程调用`fork()`创建一个子进程。子进程是父进程的一个精确副本。
2.  **`exec()`**: 子进程调用`exec()`家族中的一个函数，用新程序替换掉自己。
3.  **父进程**: 父进程可以调用`wait()`等待子进程结束，并获取其退出状态。

这种“克隆再变身”的模式非常灵活和强大。

## 实现原理 (`sys_execv`)
在我们的系统中，`sys_execv(path, argv)`的实现步骤如下：
1.  **加载程序 (`load`)**:
    -   调用`sys_open`打开可执行文件`path`。
    -   读取并校验[[ELF]]文件头。
    -   遍历程序头表，对于`PT_LOAD`类型的段，调用`segment_load`将其从文件加载到内存。
    -   `segment_load`会为新程序段分配物理页，并建立页表映射。如果老进程的页表已经覆盖了该虚拟地址，则直接复用物理页。
    -   `load`函数成功后返回新程序的入口地址（`e_entry`）。
2.  **修改进程名**: 将当前进程的名称修改为新程序的名称。
3.  **修改内核栈 (`intr_stack`)**:
    -   `eax`和`ecx`等寄存器会被清零或用于传递`argc`/`argv`。
    -   **`eip`**: 修改为`load`函数返回的新程序入口地址。
    -   **`esp`**: 修改为用户空间的最高地址（如`0xc0000000`），为新程序准备一个干净的栈。
4.  **跳转**: `jmp`到`intr_exit`，通过“伪造中断返回”的方式，让[[中央处理器 (CPU)]]从Ring 0切换到Ring 3，并从新的`eip`和`esp`开始执行新程序。
