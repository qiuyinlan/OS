# shell

**shell**，即“外壳”程序，是[[操作系统]]提供给用户的交互式接口。它接收用户输入的命令，解析命令，然后执行相应的程序或操作。

## 核心功能
1.  **命令提示符**: 显示一个提示符（如 `[rabbit@localhost /]$`），告知用户系统已准备好接收命令。
2.  **读取输入**: 从键盘（或标准输入）读取用户键入的命令字符串。
3.  **解析命令**:
    -   将命令行字符串分解成命令名和参数列表（`argv`）。
    -   识别特殊字符，如管道符 `|`。
4.  **执行命令**:
    -   **内置命令**: 如果命令是`shell`内置的（如 `cd`, `pwd`, `ps`），则直接调用内核中对应的函数。
    -   **外部命令**: 如果命令是外部程序，`shell`会：
        1.  调用`fork()`创建一个子进程。
        2.  子进程调用`exec()`加载并执行该外部程序。
        3.  父进程（`shell`）调用`wait()`等待子进程结束。

## 在我们的系统中的实现
我们的`my_shell`是一个简单的`shell`，在`init`进程的子进程中运行。
- **`readline()`**: 负责读取用户输入，并支持`Ctrl+l`（清屏）和`Ctrl+u`（清除输入）等快捷键。
- **`cmd_parse()`**: 负责解析命令行。
- **`cmd_execute()`**: 包含一个大的`if-else if`结构，用于判断是哪个内置命令并调用相应的`buildin_xxx`函数；如果都不是，则作为外部命令处理。
- **路径解析**: `make_clear_abs_path()`函数会将用户输入的相对路径或包含`.`/`..`的路径转换为干净的绝对路径，然后再传递给[[系统调用]]。
- **管道支持**: 支持`|`操作符，通过`sys_pipe()`创建[[管道]]，并使用`sys_fd_redirect()`进行[[输入输出重定向]]，实现命令间的输出到输入。
