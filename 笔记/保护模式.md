# 保护模式

**保护模式 (Protected Mode)** 是 x86系列[[中央处理器 (CPU)]]的一种操作模式，是现代[[操作系统]]运行的基础。它提供了[[分段]]和[[分页]]两种内存管理机制，以及硬件支持的[[特权级]]保护机制。

与[[实模式]]相比，它提供了许多高级特性。

## 核心特性
- **内存保护**: 通过[[段]]描述符中的界限和属性，以及[[分页机制&PDEPTE|分页机制]]，防止程序访问不属于自己的内存空间。
- **多任务**: 硬件支持任务切换（通过[[TSS]]）。
- **虚拟内存**: 能够使用硬盘空间作为内存的扩展，使得程序可用的内存远超物理内存大小。
- **特权级**: 将代码分为不同权限级别（Ring 0 到 Ring 3），限制低权限代码对核心资源的访问。
