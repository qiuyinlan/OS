# DPT (磁盘分区表)

**DPT**，全称为**磁盘分区表**（Disk Partition Table），是存放在[[MBR主引导记录]]中的一个核心[[数据]]结构。它描述了[[硬盘]]是如何被划分为多个逻辑区域（即[[分区]]）的。

## 核心作用
- **磁盘地图**: DPT就像一张地图，记录了每个[[分区]]的起始位置、大小、类型等关键信息。
- **定位分区**: [[操作系统]]在启动时会读取DPT，以了解[[硬盘]]的布局，并找到需要挂载的[[文件系统]]或要启动的系统所在[[分区]]。

## 结构与位置
- **位置**: DPT位于[[MBR主引导记录]]的512字节扇区中，从偏移地址`0x1BE`开始。
- **大小**: DPT总共占用64个字节。
- **分区表项 (Partition Entry)**: DPT由**4个**分区表项组成，每个表项占用**16个字节**，用于描述一个主[[分区]]或一个扩展[[分区]]。

### 16字节的分区表项结构
| 偏移量 | 大小(字节) | 描述 |
|---|---|---|
| 0x00 | 1 | 引导标志 (0x80=活动分区, 0x00=非活动) |
| 0x01 | 3 | 分区起始磁头、扇区、柱面号 ([[CHSLBA|CHS地址]]) |
| 0x04 | 1 | **分区类型ID** (如0x83表示Linux分区) |
| 0x05 | 3 | 分区结束磁头、扇区、柱面号 ([[CHSLBA|CHS地址]]) |
| 0x08 | 4 | **分区起始的LBA扇区号** ([[逻辑块地址 (LBA)]]) |
| 0x0C | 4 | **分区的总扇区数** |

## MBR分区的局限性
- **最多4个主分区**: 由于DPT只有64字节，最多只能定义4个分区表项。为了创建更多分区，其中一个主分区必须被定义为“扩展分区”，然后在扩展分区内部创建[[逻辑分区]]。
- **2TB容量限制**: DPT使用32位（4字节）来表示分区的起始LBA地址和总扇区数，这导致它能管理的最大[[硬盘]]容量被限制在2TB。

由于这些限制，现代系统大多采用更先进的**GPT（GUID分区表）**方案来替代MBR/DPT。
