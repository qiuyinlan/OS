# 固态硬盘 (SSD - Solid State Drive)

**固态硬盘**（SSD）是一种使用[[集成电路]]组装的、以[[固态存储]]取代传统旋转磁性介质的[[数据]]存储设备。

## 核心特性与优势
与传统的[[硬盘]]（HDD）相比，固态硬盘最大的特点是**没有机械运动部件**，这带来了多方面的优势：

1.  **速度极快**: 随机读写速度和连续读写速度都远超[[硬盘]]。
    -   更快的[[操作系统]]启动时间。
    -   更快的[[程序]]加载速度。
    -   更快的文件传输速度。
2.  **抗震防摔**: 由于没有活动部件，SSD对物理冲击和震动具有更高的抵抗力。
3.  **无噪音**: 运行过程中完全静音。
4.  **低功耗**: 消耗更少的电力。
5.  **发热量小**: 产生更少的热量。

## 技术原理
SSD主要使用**NAND闪存**（Flash Memory）作为存储介质。NAND闪存是一种非易失性[[存储介质]]，即使断电也能保存[[数据]]。

## 接口标准
SSD可以采用多种接口标准连接到[[计算机]]：
-   **SATA**: 最常见的传统[[硬盘]]接口，速度受限于SATA协议。
-   **NVMe (Non-Volatile Memory Express)**: 一种专为SSD设计的高速接口协议，通过PCIe总线直接与[[中央处理器 (CPU)]]通信，提供远高于SATA的速度。

## 缺点
-   **价格较高**: 相较于同容量的[[硬盘]]，SSD的价格通常更高。
-   **写入寿命限制**: 闪存的擦写次数是有限的。虽然现代SSD通过磨损均衡等技术大大延长了寿命，但理论上其写入寿命仍不及[[硬盘]]。
