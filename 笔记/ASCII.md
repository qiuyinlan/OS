# ASCII (American Standard Code for Information Interchange)

**ASCII** 是一套基于拉丁字母的字符编码标准，是现代计算机中最基本、最通用的编码系统之一。

## 核心思想
- **编码**: 为英文字母、数字、标点符号和一些控制字符，分配一个唯一的7位二进制数字（0-127）。
- **标准化**: 使得不同的计算机和设备能够以统一的方式表示和交换文本信息。

## 结构
- **7位编码**: 标准ASCII码使用7个比特位，可以表示 `2^7 = 128` 个不同的字符。
- **控制字符 (0-31)**: 包括回车、换行、制表符等不可打印的字符，用于控制打印机等设备。
- **可打印字符 (32-127)**:
    -   数字 (`0`-`9`)
    -   大写字母 (`A`-`Z`)
    -   小写字母 (`a`-`z`)
    -   各种标点符号和特殊符号。

## 扩展ASCII与Unicode
- **扩展ASCII**: 由于7位只能表示128个字符，无法满足其他语言的需求，因此出现了使用8位（256个字符）的各种扩展ASCII编码，但这些扩展编码之间互不兼容。
- **[[Unicode]]**: 为了统一所有语言的编码，[[Unicode]]应运而生。它为世界上几乎所有的字符都分配了一个唯一的码点。UTF-8是[[Unicode]]最常用的一种实现方式，它的设计与ASCII兼容（ASCII的前128个字符在UTF-8中的表示完全相同）。

## 在本项目中的应用
- 我们在实现[[内核打印]]功能时，从[[键盘扫描码]]转换成的最终字符，就是ASCII码。
- 在屏幕上显示的文本、在文件中存储的[[代码]]，其底层表示都是基于ASCII（或其兼容扩展，如UTF-8）。
