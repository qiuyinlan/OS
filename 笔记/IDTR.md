# IDTR (Interrupt Descriptor Table Register)

**IDTR** 是x86架构中的一个专用[[中央处理器 (CPU)]][[寄存器]]，全称为**中断描述符表寄存器**（Interrupt Descriptor Table Register）。

## 核心功能
- **定位IDT**: IDTR的唯一作用就是告诉[[中央处理器 (CPU)]]**“[[中断描述符表 (IDT)]]在[[内存]]中的哪个位置，以及它有多大”**。
- 当一个[[中断]]或[[异常 (Exception)]]发生时，[[中央处理器 (CPU)]]需要查询[[中断描述符表 (IDT)]]来找到对应的处理程序。IDTR就是[[中央处理器 (CPU)]]找到IDT的“寻路指针”。

## 结构
IDTR寄存器总共占据48位（6字节）：
- **16位 Limit (界限)**:
    -   存储了[[中断描述符表 (IDT)]]的大小。
    -   `Limit = (IDT总字节数) - 1`。例如，如果IDT有256个描述符，每个描述符8字节，那么总大小为`256 * 8 = 2048`字节，此时Limit字段的值应为`2047`。
- **32位 Base Address (基地址)**:
    -   存储了[[中断描述符表 (IDT)]]在[[物理内存]]中的起始地址。

## 加载IDTR
- IDTR不能被直接修改，必须通过专门的[[指令]]`lidt`（Load Interrupt Descriptor Table Register）来加载。
- `lidt`[[指令]]需要一个指向[[内存]]中一个6字节数据结构的指针作为操作数，这个数据结构包含了要加载到IDTR的16位Limit和32位Base。
- 在[[操作系统]]启动的早期阶段，内核必须在[[内存]]中构建好自己的[[中断描述符表 (IDT)]]，然后使用`lidt`[[指令]]将IDT的地址和大小加载到IDTR中，以完成[[中断]]机制的初始化。

## 与GDTR的对比
- **[[IDTR]]**: 指向[[中断描述符表 (IDT)]]，用于[[中断]]和[[异常 (Exception)]]处理。
- **[[GDT-GDTR-LGDT|GDTR]]**: 指向[[GDT-GDTR-LGDT|GDT]]（全局描述符表），用于[[内存]][[分段]]和地址翻译。
- 两者的结构和工作原理非常相似，都是为[[中央处理器 (CPU)]]提供“查表”的基地址和界限。
