# Unicode

**Unicode** 是一个全球性的字符编码标准，旨在为世界上每一种语言中的每一个字符提供一个唯一的数字标识（称为**码点**，Code Point）。

## 核心目标
- **统一编码**: 解决历史遗留的、成百上千种互不兼容的字符编码（如`GBK`, `Big5`, `ISO 8859-1`）所带来的混乱问题。
- **全球化支持**: 让计算机能够以统一的方式处理、存储和显示来自世界各地的文本。

## Unicode vs. UTF-8
这是一个非常容易混淆的概念：
- **Unicode**: 是一个**标准**，一个**字符集**。它只规定了每个字符的唯一编号（码点），例如，“你”字的码点是 `U+4F60`。它不关心这个码点在计算机中具体如何存储。
- **UTF-8 (Unicode Transformation Format - 8-bit)**: 是Unicode标准的一种**实现方式**，一种**编码规则**。它定义了如何将一个Unicode码点转换为计算机可以存储和传输的字节序列。

### UTF-8的特点
- **可变长度**: 使用1到4个字节来表示一个Unicode字符。
- **ASCII兼容**: 标准的[[ASCII]]字符（码点0-127）在UTF-8中只用1个字节表示，且编码值与ASCII码完全相同。这使得UTF-8能够无缝兼容大量现有的英文软件和系统。
- **无字节序问题**: UTF-8没有字节序（Endianness）的问题，这使得它在网络传输和跨平台文件交换中非常稳健。

由于这些优点，UTF-8已经成为互联网和现代[[操作系统]]上最主流的编码方式。
