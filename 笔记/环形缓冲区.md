# 环形缓冲区 (Circular Buffer)

**环形缓冲区**是一种固定大小的缓冲区，其工作方式如同一个环。它通过逻辑上的地址回绕，使得一块线性的内存区域可以被循环使用。

环形缓冲区是实现[[生产者与消费者问题]]的经典数据结构。

## 核心原理
- **线性存储**: 底层通常是一个固定大小的数组。
- **头尾指针**:
    - **头指针 (`head`)**: 数据写入的位置（生产者使用）。
    - **尾指针 (`tail`)**: 数据读取的位置（消费者使用）。
- **地址回绕**: 当`head`或`tail`指针移动到缓冲区的末尾时，它会自动“回绕”到缓冲区的开头。这通常通过**取模运算**来实现：`next_pos = (current_pos + 1) % buffer_size`。

## 状态判断
- **缓冲区满**: 当`head`指针即将追上`tail`指针时（`next_pos(head) == tail`），表示缓冲区已满。
- **缓冲区空**: 当`head`指针和`tail`指针相等时（`head == tail`），表示缓冲区为空。

**注意**: 为了区分“满”和“空”两种状态，环形缓冲区的实际可用容量通常是其总大小减一。

## 在我们的系统中的实现 (`ioqueue`)
我们的`ioqueue`结构就是一个[[环形缓冲区]]，用于实现[[管道]]和键盘输入缓冲。
- **`struct ioqueue`**:
    - `buf`: 存储数据的数组。
    - `head`, `tail`: 头尾指针。
    - `lock`: 保证[[互斥 (Mutual Exclusion)]]访问的[[锁]]。
    - `producer`, `consumer`: 分别记录因缓冲区满而等待的生产者线程和因缓冲区空而等待的消费者线程。
- **`ioq_putchar()` (生产者)**:
    -   若缓冲区满，则将自身记录在`producer`字段并[[阻塞]]。
    -   若不满，则在`head`位置放入数据，并移动`head`。
    -   最后，检查`consumer`字段，若有消费者在等待，则将其唤醒。
- **`ioq_getchar()` (消费者)**:
    -   若缓冲区空，则将自身记录在`consumer`字段并[[阻塞]]。
    -   若不空，则从`tail`位置取出数据，并移动`tail`。
    -   最后，检查`producer`字段，若有生产者在等待，则将其唤醒。
