# 二元信号量 (Binary Semaphore)

**二元信号量**是[[信号量 (Semaphore)]]的一种特殊类型，其内部计数器的值只能是 **0** 或 **1**。

## 核心功能
- **实现互斥访问**: 二元信号量的核心用途是实现[[互斥 (Mutual Exclusion)]]，功能上等同于[[锁 (Lock)]]。

## 工作流程
1.  **初始状态**: 信号量的值为 **1**，表示[[资源]]可用（锁是打开的）。
2.  **获取资源 (P操作 / `down`)**:
    - 第一个尝试获取资源的[[线程 (Thread)]]执行`down`操作。
    - 信号量的值从 1 变为 0。
    - 该[[线程 (Thread)]]成功获取[[资源]]（获得了锁），并进入[[临界区]]。
3.  **其他线程等待**:
    - 在第一个[[线程 (Thread)]]持有锁期间，任何其他[[线程 (Thread)]]尝试执行`down`操作时，会发现信号量的值为 0。
    - 这些[[线程 (Thread)]]将被[[阻塞]]，并进入等待队列，直到锁被释放。
4.  **释放资源 (V操作 / `up`)**:
    - 持有锁的[[线程 (Thread)]]完成[[临界区]]的操作后，执行`up`操作。
    - 信号量的值从 0 恢复为 1。
    - [[操作系统]]从等待队列中唤醒一个被[[阻塞]]的[[线程 (Thread)]]，使其可以获取[[资源]]。

## 与锁的关系
- 在很多[[操作系统]]实现中，[[锁 (Lock)]]的底层就是通过[[二元信号量]]来实现的。
- 它可以被看作是实现[[互斥锁]]的最简单、最经典的[[同步]]原语之一。
