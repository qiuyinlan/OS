# OBR (操作系统引导记录)

**OBR**，全称为**操作系统引导记录**（Operating System Boot Record），也常被称为**VBR**（Volume Boot Record，卷引导记录）或**PBR**（Partition Boot Record，分区引导记录）。它是一段存放在某个特定[[分区]]的**第一个扇区**的[[代码]]。

## 核心作用
- **加载操作系统**: OBR的核心职责是加载位于该[[分区]]内的[[操作系统]]。
- **与MBR的区别**:
    - [[MBR主引导记录]]位于整个[[硬盘]]的第一个扇区，它的任务是找到“活动分区”并执行该分区的OBR。
    - OBR位于某个具体[[分区]]的第一个扇区，它的任务是加载该[[分区]]中的[[操作系统]]内核。

## 启动链
OBR是计算机启动链中的关键一环：
`BIOS` → `[[MBR主引导记录]]` → **`OBR`** → `[[Loader加载器]]`或`[[操作系统]]内核`

## OBR的结构
一个典型的OBR扇区包含：
1.  **跳转指令**: 一条`jmp`[[指令]]，用于跳过紧随其后的BPB（BIOS Parameter Block），执行真正的引导[[代码]]。
2.  **BPB (BIOS Parameter Block)**: 描述该[[分区]][[文件系统]]布局的[[数据]]结构，例如每[[扇区]]字节数、每簇扇区数、[[FAT文件系统|FAT]]表大小等。
3.  **引导代码 (Boot Code)**: 负责在[[文件系统]]中找到[[操作系统]]的加载程序（如Windows的`bootmgr`或Linux的`GRUB`的后续阶段）或[[内核]]本身，将其加载到[[内存]]并执行。
4.  **结束标志**: 与[[MBR主引导记录]]一样，以`0x55AA`作为有效的结束标志。
