# 函数指针 (Function Pointer)

在C语言等[[编程语言]]中，**函数指针**是一种特殊的[[指针]][[变量]]，它存储的不是[[数据]]的[[内存]]地址，而是**函数在[[内存]]中可执行[[代码]]的起始地址**。

## 核心概念
- **函数即数据**: 函数指针允许我们将函数像普通[[数据]]一样进行操作，例如作为[[变量]]赋值、作为参数传递给其他函数，或者存储在[[数据结构]]中。
- **间接调用**: 通过函数指针，我们可以间接地调用其指向的函数。

## 声明语法
声明函数指针的通用语法为：
`返回类型 (*指针变量名)(参数类型1, 参数类型2, ...);`

**关键点**: `(*指针变量名)` 外面的括号是必须的，因为它告诉[[编译器]] `指针变量名` 是一个指针，指向一个函数，而不是一个返回指针的函数。

**示例**:
```c
// 声明一个函数，它接受两个整数并返回一个整数
int add(int a, int b) {
    return a + b;
}

// 声明一个函数指针变量，它可以指向接受两个整数并返回整数的函数
int (*ptr_to_add_func)(int, int); 
```

## 赋值
将一个函数的地址赋给兼容的函数指针[[变量]]。函数名本身就代表其地址，所以`&`运算符是可选的。

**示例**:
```c
ptr_to_add_func = add;    // 正确
ptr_to_add_func = &add;   // 同样正确
```

## 调用
通过函数指针调用函数有两种等效的方式：

**示例**:
```c
int result1 = ptr_to_add_func(5, 3);    // 方式一：直接使用指针名
int result2 = (*ptr_to_add_func)(10, 2); // 方式二：显式解引用指针
```

## 应用场景
- **回调函数 (Callback Functions)**: 将一个函数指针作为参数传递给另一个函数。当特定事件发生时，被调用的函数会“回调”通过指针传递的函数。这在事件处理、[[中断处理程序]]、[[系统调用]]的实现中非常常见。
- **函数表 (Function Tables)**: 将多个具有相同签名（参数和返回类型）的函数存储在一个函数指针数组中。这可以根据索引动态地选择并执行不同的函数，常用于实现状态机或命令调度器（例如[[syscall_table]]）。
- **动态行为**: 允许[[程序]]在运行时决定调用哪个函数，增加了[[程序]]的灵活性和可配置性。
