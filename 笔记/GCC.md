# GCC (GNU Compiler Collection)

**GCC**，全称为**GNU编译器套件**（GNU Compiler Collection），是由GNU项目开发的一套开源、免费的[[编译器]]集。它是[[Linux]]和许多[[类Unix操作系统|UNIX-like]]系统中最核心的开发工具之一。

## 核心功能
- **代码翻译**: GCC的主要工作是将程序员用[[高级语言]]（如C、C++）编写的[[源码]]，翻译成特定[[中央处理器 (CPU)]]可以执行的[[机器语言]]。
- **多语言支持**: 虽然最初是作为C语言[[编译器]]（GNU C Compiler），但现在已发展为支持多种[[编程语言]]的[[编译器]]套件，包括C++, Objective-C, Fortran, Ada, Go等。
- **跨平台编译**: GCC支持在一种平台上（如x86的[[Linux]]）生成另一种平台（如ARM）的可执行[[程序]]，这对于嵌入式开发至关重要。

## 编译流程
GCC的编译过程通常分为四个主要阶段：
1.  **预处理 (Preprocessing)**: 处理[[源码]]中的预处理指令（如`#include`, `#define`）。
2.  **编译 (Compilation)**: 将预处理后的[[代码]]翻译成[[汇编语言]]。
3.  **汇编 (Assembly)**: 将[[汇编语言]][[代码]]转换成机器可读的目标文件（Object File，通常是`.o`文件）。
4.  **链接 (Linking)**: 将一个或多个目标文件与所需的库文件（如[[标准库libc|C标准库]]）链接起来，生成最终的可执行[[程序]]。

## 在本项目中的作用
在我们的[[操作系统]]开发项目中，GCC是构建内核的绝对主力。我们用它来：
- 将所有C语言编写的[[内核]]功能模块（如[[内存管理]]、[[进程调度]]、[[文件系统]]等）[[编译]]成目标文件。
- 与[[nasm]]编译的汇编代码目标文件一起，通过[[链接器]]（ld）组合成最终的[[内核]]可执行文件（通常为[[ELF文件|ELF]]格式）。
