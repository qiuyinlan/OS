# Fault (故障)

**Fault** 是x86架构中三种[[异常 (Exception)]]类型（Fault, Trap, Abort）之一。它是一种通常**可以被修复**的[[异常 (Exception)]]。

## 核心特性
- **可纠正**: Fault表示[[中央处理器 (CPU)]]在执行[[指令]]时遇到了一个问题，但这个问题通常可以被[[操作系统]]的[[中断处理程序]]解决。
- **可重启**: Fault最重要的特性是，在[[中断处理程序]]解决问题之后，[[中央处理器 (CPU)]]会**重新执行**导致了Fault的那条[[指令]]。
- **EIP指向**: 当Fault发生时，[[中央处理器 (CPU)]]保存的[[EIP]]（指令指针）**指向导致异常的指令本身**，而不是下一条[[指令]]。这使得修复问题后能够重新尝试执行该[[指令]]。

## 典型的Fault示例
- **[[缺页异常 (Page Fault)]]**: 这是最经典和最常见的Fault。当[[程序]]访问一个不在[[物理内存]]中的[[页面]]时触发。
    - **处理流程**: [[操作系统]]捕获这个Fault，从[[硬盘]]加载所需的[[页面]]到[[物理内存]]，更新[[页表]]，然后返回。[[中央处理器 (CPU)]]重新执行导致Fault的[[指令]]，此时[[内存]]访问成功，[[程序]]可以继续正常运行。
- **段不存在异常 (#NP)**: 访问一个“不存在”（描述符中的P位为0）的[[段]]时触发。
- **栈错误 (#SS)**: 对[[栈]]的操作超出了[[栈]][[段]]的界限时触发。
- **通用保护异常 (#GP)**: 各种权限相关的错误，例如试图向只读[[段]]写入[[数据]]。

## 与Trap和Abort的区别
- **[[Fault]]**: `EIP`指向**当前**[[指令]]，可修复，处理后**重新执行**。
- **[[Trap]]**: `EIP`指向**下一条**[[指令]]，通常是故意触发的，处理后**继续执行**。
- **[[Abort]]**: `EIP`位置不确定，是严重错误，**无法恢复**。
