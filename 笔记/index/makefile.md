# Makefile

`Makefile` 是一个文本文件，它包含了一系列的**规则**，用于指导 `make` 构建工具如何[[编译]]和[[链接]]一个程序。它是自动化构建过程的核心。

## 核心作用
- **自动化构建**: `make` 读取 `makefile` 文件后，可以自动完成整个项目的[[编译]]、[[链接]]等任务。
- **增量编译**: `make`最强大的功能是能够判断哪些文件被修改过，并只对这些文件以及依赖它们的文件进行重新[[编译]]，从而大大节省了大型项目的构建时间。

## 基本语法
`makefile`由一系列的**规则**组成，每条规则的格式如下：

```makefile
目标文件: 依赖文件1 依赖文件2 ...
	[Tab]命令1
	[Tab]命令2
```

- **目标 (Target)**: 规则想要生成的文件，通常是目标文件 (`.o`) 或可执行文件。
- **依赖 (Prerequisites/Dependencies)**: 创建“目标”所需要的文件或其他的“目标”。
- **命令 (Commands)**: 创建“目标”所需要执行的[[Shell]]命令。**非常重要：每行命令都必须以一个 `Tab` 字符开始，而不是空格。**

## 工作原理
1. `make` 会找到要构建的“目标”。
2. `make` 检查该“目标”的所有“依赖”文件。
3. `make` 比较“目标”文件和“依赖”文件的**最后修改时间** ([[mtime]])。
4. 如果任何一个“依赖”比“目标”**新**，或者“目标”文件不存在，`make` 就会执行该规则下的“命令”来重新生成“目标”。

这个检查过程是递归的，`make`会确保所有的依赖都首先被更新，然后再生成最终的目标。
