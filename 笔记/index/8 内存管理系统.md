# 第8章 内存管理系统

随着项目文件增多，手动[[编译]]和[[链接]]变得繁琐。为了更高效地开发，我们需要引入构建工具。

## 8.1 makefile简介
[[Makefile]]是 [[Linux]] 环境下用于管理大型程序[[编译]]的工具。它可以帮助我们自动化构建过程。

### 8.1.1 makefile是什么
- **问题**: 大型程序由多个模块构成，修改部分文件后，如何只[[编译]]受影响的文件，而不是整个项目？
- **解决方案**: `make`命令配合`makefile`文件。
    - `makefile` 文件：定义了文件间的[[依赖关系]]和生成规则。
    - `make` 命令：解析 `makefile`，找出被更新的文件，并根据依赖关系找到所有受影响的相关文件，然后执行预定义的命令。

- **核心逻辑**:
    1.  目标文件依赖哪些文件？
    2.  依赖的文件是否已更新？
- `make`通过比较文件的[[mtime]]来判断文件是否需要重新[[编译]]。
- `make`本身不负责[[编译]]，它只是一个规则执行引擎，通常调用[[gcc]]、[[nasm]]等[[编译]]器来完成工作。

### 8.1.2 makefile基本语法
一组规则包含三部分：

```
目标文件：依赖文件
	[Tab]命令
```

1.  **目标文件**: 规则想要生成的文件，如 `.o` 文件或可执行文件。
2.  **依赖文件**: 生成目标文件所需要的文件列表。
3.  **命令**: 生成目标文件需要执行的[[Shell]]命令。**每条命令必须以`Tab`键开头**。

- **规则的意义**: 如果任何一个`依赖文件`比`目标文件`要新（根据[[mtime]]判断），就执行`命令`来重新生成`目标文件`。

- **文件时间戳**:
    - `atime` (access time): 文件数据最后被访问的时间。
    - `ctime` (change time): 文件属性（如权限、所有者）或数据最后被改变的时间。
    - `mtime` (modification time): 文件**数据**（内容）最后被修改的时间。`make`主要关心`mtime`。
