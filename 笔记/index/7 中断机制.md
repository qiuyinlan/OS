# 第7章 中断机制

## 7.1 中断是什么,为什么要有中断
[[中断]]是什么?这里所说的是发生在计算机世界里的[[中断]]。
由于[[中央处理器 (CPU)]] 获知了计算机中发生的某些事， [[中央处理器 (CPU)]] 暂停正在执行的程序，转而去执行处理该事件的程序， 当这段程序执行完毕后，[[中央处理器 (CPU)]] 继续执行刚才的程序。整个过程称为[[中断处理]]，也称为[[中断]]。

通俗地说，[[中断]]的意思是打断正在做的事。[[中断]]是提升整个系统利用率最有效的方式，因为有了[[中断]]，系统才能[[并发]]运行。

- [[并发]]与[[并行]]的区别：
    - **[[并发]]**: 指的是单位时间内的累积工作量。单核[[中央处理器 (CPU)]]谈[[并发]]。
    - **[[并行]]**: 指是指真正同时进行的工作量。多核[[中央处理器 (CPU)]]谈[[并行]]。

正是因为有了[[中断]]，我们才可以“同时”享受计算机的多种服务。运用[[中断]]能够显著提升[[并发]]，从而大幅提升效率。

## 7.2 操作系统是中断驱动的
“没有[[中断]]，[[操作系统]]几乎什么都做不了，[[操作系统]]是[[中断驱动]]的”。
[[操作系统]]本质上是一个等待事件发生的死循环。事件以[[中断]]的形式通知[[操作系统]]，所以说，[[操作系统]]是[[中断驱动]]的。

## 7.3 中断分类
把[[中断]]按事件来源分类，来自[[中央处理器 (CPU)]]外部的[[中断]]就称为[[外部中断]]，来自[[中央处理器 (CPU)]]内部的[[中断]]称为[[内部中断]]。
- **[[外部中断]]**: 按是否导致宕机来划分，可分为[[可屏蔽中断]]和[[不可屏蔽中断 (NMI)]]。
- **[[内部中断]]**: 按[[中断]]是否正常来划分，可分为[[软中断]]和[[异常 (Exception)]]。

### 7.3.1 外部中断
[[外部中断]]是指来自 [[中央处理器 (CPU)]] 外部的[[中断]]，中断源必须是某个[[硬件]]，所以[[外部中断]]又称为[[硬件中断]]。
[[中央处理器 (CPU)]]通过两条信号线接收外部硬件的[[中断]]：`INTR` (INTeRrupt) 和 `NMI` (Non Maskable Interrupt)。

- **[[可屏蔽中断]]**:
    - 通过 `INTR` 引脚进入[[中央处理器 (CPU)]]。
    - 外部设备如[[硬盘]]、[[网卡]]发出的[[中断]]都是[[可屏蔽中断]]。
    - "可屏蔽"意味着[[中央处理器 (CPU)]]可以不理会，因为它不会让系统宕机。
    - 可以通过 [[EFLAGS寄存器]] 的 `IF` 位将所有这些[[外部中断]]屏蔽。
    - 中断处理可以分为[[中断上半部和下半部]]，以提高响应效率。

- **[[不可屏蔽中断 (NMI)]]**:
    - 通过 `NMI` 引脚进入[[中央处理器 (CPU)]]。
    - 表示系统中发生了致命的错误，如[[内存读写错误]]、电源掉电等。
    - “不可屏蔽”不是指“不建议屏蔽”，而是错误已经发生，无法通过软件层面忽略或修复，宕机不可避免。
    - [[EFLAGS寄存器]]中的`IF`位对其无效。
    - [[不可屏蔽中断 (NMI)]]的中断向量号固定为2。

### 7.3.2 内部中断
[[内部中断]]可分为[[软中断]]和[[异常 (Exception)]]。

- **[[软中断]]**:
    - 由软件主动发起的中断，如 `int 8位立即数` 指令。
    - `int3` 是调试断点指令，触发3号中断。
    - `into` 是溢出中断指令，检查 `OF` 位，触发4号中断。
    - `bound` 是数组越界检查指令，触发5号中断。
    - `ud2` 是未定义指令，触发6号中断。

- **[[异常 (Exception)]]**:
    - 指令执行期间[[中央处理器 (CPU)]]内部产生的错误引起的[[内部中断]]。
    - 不受 `IF` 位影响。
    - 分为三种类型：
        1. **[[Fault]] (故障)**: 可修复的错误。[[中央处理器 (CPU)]]会将机器状态恢复到异常之前的状态，返回地址指向导致异常的指令，以便修复后重试。最典型的例子是[[缺页异常 (Page Fault)]]。
        2. **[[Trap]] (陷阱)**: 通常用于调试，如 `int3` 指令。[[中央处理器 (CPU)]]将返回地址指向异常指令的**下一条**指令。
        3. **[[Abort]] (终止)**: 最严重的[[异常 (Exception)]]，通常是硬件错误或系统数据结构出错，无法修复，程序将被终止。

## 7.4 中断描述符表 (IDT)
[[中断描述符表 (IDT)]]是[[保护模式]]下用于存储[[中断处理程序]]入口的表。
- 在[[实模式]]下，对应的表叫[[中断向量表]]，位于 `0x00000 - 0x003FF`。
- [[中断描述符表 (IDT)]]的位置不固定，其地址和大小由[[IDTR]]寄存器指定。
- [[中断描述符表 (IDT)]]中的描述符被称为[[门描述符]]，大小为8字节。

### 门描述符
[[门描述符]]是通往一段代码的入口，都属于[[系统段]]（S=0）。
1.  **[[任务门 (Task Gate)]]**: 与[[TSS]]配合，用于硬件任务切换。Type值为`0101`。
2.  **[[中断门]]**: 包含[[中断处理程序]]的[[段选择子]]和偏移。通过[[中断门]]进入中断后，`EFLAGS`的`IF`位**会自动置0**（关中断）。Type值为`1110`。
3.  **[[陷阱门 (Trap Gate)]]**: 与[[中断门]]类似，但`IF`位**不会自动置0**。Type值为`1111`。
4.  **[[调用门 (Call Gate)]]**: 提供用户进程进入特权0级的方式，只能用`call`和`jmp`指令调用。Type值为`1100`。

### 中断处理过程及保护
1.  **定位描述符**：[[中央处理器 (CPU)]]用[[中断向量号]] * 8 + [[IDTR]].base，找到对应的[[门描述符]]。
2.  **特权级检查**：
    -   对于[[软中断]]，检查 `CPL <= 门DPL` 和 `CPL >= 目标代码段DPL`（数值上）。
    -   对于[[外部中断]]和[[异常 (Exception)]]，只检查 `CPL >= 目标代码段DPL`（数值上）。
3.  **执行中断处理程序**：加载[[CS]]:[[EIP]]，开始执行。
    -   如果通过[[中断门]]，`IF`位自动清0。
    -   [[中断返回]]使用 `iret` 指令，它会从[[栈]]中恢复 `EIP`、`CS`、`EFLAGS` 等。
    -   `cli` 指令用于关中断 (`IF=0`)，`sti` 用于开中断 (`IF=1`)。

### 中断发生时的压栈
当中断发生时，[[中央处理器 (CPU)]]会自动向[[栈]]中压入数据以保存现场。
- **有特权级变化**: 压入 `SS_old`, `ESP_old`, `EFLAGS`, `CS_old`, `EIP_old`，以及可能的[[错误码 (error code)]]。
- **无特权级变化**: 压入 `EFLAGS`, `CS_old`, `EIP_old`，以及可能的[[错误码 (error code)]]。

### 中断错误码
- [[错误码 (error code)]]提供[[中断]]发生位置的线索。
- 本质上是一个特殊的[[段选择子]]，包含`EXT`、`IDT`、`TI`位和索引。
- `iret` 指令不会自动弹出[[错误码 (error code)]]，需要手动处理[[栈]]指针。

## 7.5 可编程中断控制器 (PIC) 8259A
[[可编程中断控制器 (PIC) 8259A]]是管理[[可屏蔽中断]]的[[中断]]代理芯片。
- **功能**: 屏蔽外设[[中断]]、进行优先级判决、向[[中央处理器 (CPU)]]提供[[中断向量号]]。
- **级联**: PC中通常有两片[[可编程中断控制器 (PIC) 8259A]]（主片和从片）通过[[级联]]方式工作，提供15个[[IRQ]]（Interrupt ReQuest）接口。
- **内部寄存器**:
    - `IMR` (Interrupt Mask Register): 中断屏蔽寄存器。
    - `IRR` (Interrupt Request Register): 中断请求寄存器，等待处理的[[中断]]队列。
    - `ISR` (In-Service Register): 中断服务寄存器，记录正在被处理的[[中断]]。
- **工作流程**:
    1. 外设通过[[IRQ]]线发出信号。
    2. [[可编程中断控制器 (PIC) 8259A]]检查`IMR`，若未屏蔽，则在`IRR`中置位。
    3. 优先级仲裁器`PR`选出最高优先级的中断。
    4. [[可编程中断控制器 (PIC) 8259A]]向[[中央处理器 (CPU)]]的`INTR`引脚发信号。
    5. [[中央处理器 (CPU)]]响应，通过`INTA`回复。
    6. [[可编程中断控制器 (PIC) 8259A]]将`IRR`清零，在`ISR`中置位。
    7. [[中央处理器 (CPU)]]再次发`INTA`，请求[[中断向量号]]。
    8. [[可编程中断控制器 (PIC) 8259A]]将计算好的[[中断向量号]]发送给[[中央处理器 (CPU)]]。
    9. [[中央处理器 (CPU)]]执行对应的[[中断处理程序]]。
    10. [[中断处理程序]]结束时，需向[[可编程中断控制器 (PIC) 8259A]]发送[[EOI]]命令，清零`ISR`中的对应位。

### 8259A的编程
通过向[[IO端口]]写入初始化命令字([[ICW]])和操作命令字([[OCW]])来对[[可编程中断控制器 (PIC) 8259A]]编程。
- **端口**: 主片(0x20, 0x21)，从片(0xA0, 0xA1)。
- **[[ICW]] (Initialization Command Words)**:
    - `ICW1`: 设置连接方式（级联/单片）和触发方式。
    - `ICW2`: 设置起始[[中断向量号]]。
    - `ICW3`: 设置主从片的连接关系。
    - `ICW4`: 设置工作模式（如x86模式，手动/自动[[EOI]]）。
- **[[OCW]] (Operation Command Word)**:
    - `OCW1`: 写入`IMR`，用于屏蔽/允许特定[[IRQ]]。
    - `OCW2`: 设置优先级模式和发送[[EOI]]命令。
    - `OCW3`: 设置特殊屏蔽和查询方式。

## 7.6 编写中断处理程序
这是一个循序渐进的过程，包含汇编和C代码。
1. **定义中断入口**: 在汇编（`kernel.S`）中使用宏定义多个[[中断处理程序]]的入口(`intrXXentry`)。
2. **统一栈帧**: 对于没有[[错误码 (error code)]]的[[中断]]，手动`push 0`，以保证所有[[中断]]处理前[[栈]]的结构一致。
3. **创建IDT**: 在C代码（`interrupt.c`）中定义`struct gate_desc`，并创建[[中断描述符表 (IDT)]]数组。
4. **安装处理程序**: 编写`make_idt_desc`函数，将汇编中定义的中断入口地址填充到[[中断描述符表 (IDT)]]的[[中断门描述符]]中。
5. **加载IDT**: 使用`lidt`指令将[[中断描述符表 (IDT)]]的地址和界限加载到[[IDTR]]寄存器。
6. **初始化8259A**: 调用`pic_init`函数，通过`outb`向端口写入一系列[[ICW]]和[[OCW]]，配置好[[可编程中断控制器 (PIC) 8259A]]。
7. **开启中断**: 执行`sti`指令，将`EFLAGS`的`IF`位置1，允许[[中央处理器 (CPU)]]响应[[可屏蔽中断]]。

## 7.7 可编程计数器/定时器8253简介
[[8253]] (或[[可编程计数器 (PIT) 8253]]) 是一个可编程的硬件定时/计数器。
- **作用**: 其[[计数器0]]用于产生实时的[[时钟中断]]信号，该信号连接到[[可编程中断控制器 (PIC) 8259A]]的`IRQ0`引脚。
- **内部结构**: 包含3个独立的16位减法[[计数器]]（0, 1, 2）。
- **工作原理**: 对一个高频的输入时钟信号（`1.19318MHz`）进行[[分频]]，当计数值减到0时，在`OUT`引脚产生一个输出信号（即[[时钟中断]]）。

### 8253 编程
- **控制字寄存器 (0x43)**: 写入控制字，用于选择[[计数器]]、设置工作方式（如方式2-比率发生器）、读写格式和数制（二进制/BCD）。
- **计数器端口 (0x40-0x42)**: 写入16位的[[计数初值]]。

### 改变时钟频率
- **公式**: `中断频率 = 1193180 / 计数初值`
- **目标**: 要将中断频率设为 `100Hz`，需要计算出新的[[计数初值]] `11932`。
- **实现**:
    1.  向控制端口`0x43`写入控制字，选择[[计数器0]]，工作方式2，读写16位。
    2.  向[[计数器0]]的数据端口`0x40`先写入初值的低8位，再写入高8位。
    3.  在`init_all`中调用`timer_init`完成初始化。
