# 回调函数 (Callback Function)

**回调函数**是一种[[编程]]模式，它指的是一个[[函数]]被作为参数传递给另一个[[函数]]，并在后者内部的某个特定时机被调用。

## 核心概念
- **作为参数的函数**: 回调函数本质上是一个被当作[[数据]]一样传递的[[函数]]。
- **“稍后调用”**: 接收回调函数的[[函数]]（通常称为“高阶函数”或“调用方函数”）会在其执行流程的某个点（通常是某个事件发生后或某个操作完成时）“回调”这个被传递进来的函数。

## 为什么使用回调函数？
回调函数是实现[[异步编程]]、事件驱动编程和自定义行为的关键技术：

1.  **[[异步编程]]**:
    -   当一个操作（如[[文件]]读写、网络请求）需要较长时间才能完成时，[[程序]]可以不等待其结果，而是继续执行其他[[代码]]。
    -   操作完成后，会调用事先指定的回调函数来处理结果。这避免了[[忙等待]]，提高了[[程序]]的响应性。
2.  **事件处理**:
    -   在图形用户界面（GUI）编程中，当用户点击按钮、按下[[键盘]]等事件发生时，系统会调用注册好的回调函数来响应这些事件。
3.  **自定义行为**:
    -   回调函数允许一个通用[[函数]]具备可定制的行为。例如，一个排序函数可以接受一个比较函数作为回调，从而支持不同的排序逻辑。
4.  **[[中断处理程序]]**:
    -   在[[操作系统]]底层，[[中断处理程序]]在某种意义上就是[[硬件]]或[[软件中断]]发生时的“回调函数”，[[CPU]]会跳转到注册好的[[中断处理程序]]地址执行。

## 示例 (C语言)
```c
// 定义一个回调函数的类型 (函数指针)
typedef void (*CallbackFunc)(int result);

// 模拟一个异步操作
void performAsyncOperation(int input, CallbackFunc callback) {
    // ... 模拟耗时操作 ...
    int calculatedResult = input * 2;
    // 操作完成后，调用回调函数
    if (callback != NULL) {
        callback(calculatedResult);
    }
}

// 这是一个将作为回调的函数
void myCallback(int result) {
    printf("Async operation finished with result: %d\n", result);
}

int main() {
    performAsyncOperation(10, myCallback); // 传递myCallback作为参数
    printf("Main program continues...\n");
    return 0;
}
```
