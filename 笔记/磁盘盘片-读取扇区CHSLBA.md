# 前置：硬盘读一个扇区必须做的 4 件事

读硬盘（IDE / ATA）需要按顺序给硬盘控制器写 **端口寄存器**：

|端口|功能|
|---|---|
|0x1F2|要读几个扇区|
|0x1F3|LBA 地址低 8 位|
|0x1F4|LBA 地址中 8 位|
|0x1F5|LBA 地址高 8 位|
|0x1F6|LBA 第 24-27 位 + 主/从盘选择|
|0x1F7|命令 / 状态寄存器（读写不同）|

MBR 的读盘函数就是按这个顺序来。

现在逐句解释你问的这几行👇👇👇

---

# ✅ 1. 写 0x1F2：扇区数 = 1

`mov dx, 0x1F2 mov al, cl     ; cl = 1 out dx, al`

意思是：

> **告诉硬盘：我这次要读几个扇区？**

你读 loader 只有 1 个扇区（512 字节），所以写 1。

如果你写 4，硬盘就会连续读 4 个扇区。

---

# ✅ 2. 写 0x1F3–0x1F6：LBA 地址 = 2

硬盘访问扇区时必须告诉它：

> “我要读哪个扇区？（LBA 地址）”

例如 LBA = 2：

`0x1F3 ← 2 的低 8 位 0x1F4 ← 2 的中 8 位 0x1F5 ← 2 的高 8 位 0x1F6 ← 1010xxxx + LBA 的 24~27 位`

汇编大概长这样：

`mov dx, 0x1F3 out dx, al        ; LBA0-7  mov dx, 0x1F4 out dx, ah        ; LBA8-15  shr eax, 16 mov dx, 0x1F5 out dx, al        ; LBA16-23  mov dx, 0x1F6 out dx, al        ; 主盘 + LBA24-27`

**为什么要这么拆？**  
因为硬盘的 LBA 地址寄存器没有 32 位，只能分四段写。

---

# ✅ 3. 写 0x1F7：命令 = 0x20（读扇区）

端口 0x1F7 写入命令字节：

`0x20 = READ SECTORS`

意思是：

> “我已经把扇区号+LBA都告诉你了，现在开始读吧！”

类似 C 语言：

`controller.command = READ;`

写完后，硬盘 **开始自己转盘、定位、读取扇区**。

---

# ✅ 4. 等待 0x1F7 状态 = 0x08

0x1F7 用作 **状态寄存器** 时，反映硬盘当前状态：

|状态位|含义|
|---|---|
|bit 0 (ERR)|发生错误|
|bit 3 (DRQ)|数据准备好了，可以读了|
|bit 7 (BSY)|磁盘忙，不能读写|

MBR 会反复读 0x1F7：

`wait:     in al, 0x1F7     test al, 0x08     ; DRQ == 1 ?     jz wait`

**0x08 = DRQ 位**  
表示：

> “数据已经准备好，你可以从 0x1F0 端口把 512 字节读走了。”

---

# 🔥 完整流程总结（超级清晰）

1. **告诉硬盘：我要读几个扇区** → 写 0x1F2
    
2. **告诉硬盘：我要读哪个扇区** → 写 0x1F3–0x1F6
    
3. **告诉硬盘：开始读！** → 写 0x1F7 = 0x20
    
4. **等待硬盘说：我准备好了** → 读 0x1F7 直到 DRQ = 1
    
5. **从 0x1F0 端口把 512 字节读出来** → 读入内存
    

这就是你的 MBR 正在做的事。
# 磁道与扇区
磁道（**Track**）其实是——  
👉 磁盘表面上一条**狭窄的环形磁带路径**。  
它的宽度非常小，大约只有几微米（μm）级别。

磁盘表面是涂有**磁性材料**的（比如氧化铁粉），  
磁头能在上面**改变这些微小区域的磁化方向**，  
就像“写入0和1”的信号。


# 扇区

## 扇区编号

- 扇区在每条 **磁道** 上从 0 开始编号。
    
- **磁道**可以理解为盘片上的同心圆。
    
- 不同磁道的扇区编号可以重复，比如磁道 0 的扇区 0，磁道 1 也有扇区 0。
    

## 扇区头（Sector Header）

- 每个扇区前面有==一点点信息，叫 **扇区头**==。
    
- 它告诉硬盘：
    
    1. 当前磁头号（Head）——用哪块盘片？
        
    2. 当前磁道号（Cylinder）——用哪条同心圆？
        
    3. 当前扇区号（Sector）——这一条磁道上的哪块？
        
- 磁头就是靠这个信息找到你想读或写的数据。

# 读取扇区的方式

### chs
柱面，磁头，扇区
cylinder,heads,sector
 

### LBA（Logical Block Addressing）

[[CHSLBA]]

>逻辑块寻址

lba28
最大寻址范围为28位，128gb

lba48,256tb
它的核心思想非常简单：

> 不再用 “柱面/磁头/扇区” 三个参数表示位置，  
> 而是—— **给所有扇区编上一个从 0 开始的编号**。

所以每个扇区都有一个 **唯一编号**（就像身份证号），  
BIOS、操作系统、磁盘控制器都可以直接按编号访问。
