# exit

`exit` 是一个 [[UNIX]] [[系统调用]]，用于正常终止一个进程。

## 核心行为
- **终止进程**: 调用`exit`会立即终止当前进程的执行。
- **传递退出状态**: `exit`接受一个整数参数`status`，这个值会作为进程的“退出状态”被保存起来，等待其父进程通过`wait()`来获取。
- **资源回收**: 内核在收到`exit`调用后，会回收该进程**除[[PCB]]之外**的所有资源，如内存、页表、打开的文件等。[[PCB]]之所以被保留，是因为它里面存储着`exit_status`，需要等待父进程来读取。

## 实现原理 (`sys_exit`)
在我们的系统中，`sys_exit(status)`的实现步骤如下：
1.  **保存退出状态**: 将参数`status`存入当前进程[[PCB]]的`exit_status`字段。
2.  **处理子进程 (过继)**: 遍历所有任务列表，将当前进程的所有子进程过继给`init`进程（`pid=1`）。这可以防止它们成为[[孤儿进程]]。
3.  **回收资源**: 调用`release_prog_resource`释放当前进程的所有资源（页表、虚拟内存池等）。
4.  **唤醒父进程**: 查找父进程，如果父进程的状态是`TASK_WAITING`（即父进程正在调用`wait()`等待自己），则调用`thread_unblock`将其唤醒。
5.  **变为僵尸进程**: 调用`thread_block(TASK_HANGING)`将自己挂起，等待父进程来为自己“收尸”（即回收[[PCB]]）。

## `exit` 与 `_exit`
- `_exit()`: 直接进行终止进程的[[系统调用]]。
- `exit()`: [[glibc]]库函数，它在调用`_exit()`系统调用之前，会执行一些清理工作（如刷新`stdio`缓冲区等）。
