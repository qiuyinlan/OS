# 键盘扫描码 (Keyboard Scancode)

**键盘扫描码**是当用户按下或释放键盘上的一个物理按键时，由键盘自身的硬件（[[键盘编码器 (8048)]]）产生并发送给计算机的底层[[代码]]。

## 核心特性
- **物理相关性**: 扫描码与键盘上的**物理按键位置**一一对应，而不是与该按键上印的字符（如 'A' 或 'B'）对应。
- **布局无关性**: 无论[[操作系统]]设置为哪国语言的键盘布局（QWERTY, AZERTY, Dvorak等），按下同一个物理按键，产生的扫描码总是相同的。
- **动作区分**: 按键的“按下”和“释放”会产生两种不同的扫描码：
    - **通码 (Make Code)**: 按下按键时发送。
    - **断码 (Break Code)**: 释放按键时发送。断码通常是在通码的基础上通过特定规则计算得出的（例如，将通码的最高位置1）。

## 工作流程
1.  **键盘编码器 (8048)**: 键盘内部的微控制器检测到按键动作，生成对应的扫描码。
2.  **键盘控制器 (8042)**: 主板上的芯片接收到扫描码，将其存入自己的缓冲区，并向[[中央处理器 (CPU)]]发出一个[[硬件]][[中断]]（在PC上是 `IRQ1`）。
3.  **中断处理程序**: [[操作系统]]的[[键盘]]驱动程序被[[中断]]触发，从[[键盘控制器 (8042)]]的 I/O 端口（通常是 `0x60`）读取扫描码。
4.  **翻译**: 驱动程序根据扫描码，并结合 `Shift`, `Ctrl`, `Alt` 等状态键的情况，将其翻译成[[操作系统]]内部能理解的虚拟键码或最终的[[ASCII]]/[[Unicode]]字符。

## 扫描码集
存在多种扫描码集（Scan Code Sets），但现代PC系统为了兼容性，通常由[[键盘控制器 (8042)]]统一将接收到的各种扫描码转换为**第一套扫描码集 (Scan Code Set 1)** 后再提供给[[中央处理器 (CPU)]]。因此，驱动程序通常只需要处理这一套标准即可。
