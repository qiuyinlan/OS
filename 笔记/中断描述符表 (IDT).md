# 中断描述符表 (IDT)

**中断描述符表 (Interrupt Descriptor Table, IDT)** 是[[保护模式]]下，[[中央处理器 (CPU)]]用于索引[[中断处理程序]]地址的核心数据结构。它替代了[[实模式]]下的[[中断向量表]]。

## 核心特性
- **功能**: 存储了0-255号共256个[[中断]]或[[异常 (Exception)]]对应的[[门描述符]]。
- **位置**: 不再固定于内存低地址，其线性基地址和大小由 `IDTR` 寄存器指定。
- **结构**: 每一项是一个8字节的[[门描述符]]。

## IDTR 寄存器
`IDTR` (Interrupt Descriptor Table Register) 是一个48位的寄存器，用于告诉[[中央处理器 (CPU)]] [[中断描述符表 (IDT)]]在哪里。
- **低16位**: 表界限（Limit），即 `IDT大小 - 1`。
- **高32位**: [[中断描述符表 (IDT)]]的线性基地址。
- **加载指令**: 使用 `lidt` 指令将一个48位内存操作数（包含界限和基址）加载到`IDTR`。

## IDT中的描述符类型
[[中断描述符表 (IDT)]]中只能存放[[门描述符]]，主要有以下几种：
- **[[中断门]]**: 通过它进入中断时，`EFLAGS`寄存器的`IF`位会被**自动清零**（关中断）。这是最常用的类型。
- **[[陷阱门 (Trap Gate)]]**: 通过它进入中断时，`IF`位**保持不变**。常用于调试和系统调用。
- **[[任务门 (Task Gate)]]**: 用于硬件任务切换，与[[TSS]]相关，现代[[操作系统]]较少使用。

## 查找与执行流程
1. [[中央处理器 (CPU)]]收到一个[[中断向量号]] `n`。
2. [[中央处理器 (CPU)]]计算出对应[[门描述符]]的地址：`IDTR.Base + n * 8`。
3. 读取8字节的[[门描述符]]。
4. 进行[[特权级]]检查。
5. 从[[门描述符]]中获取[[中断处理程序]]的[[段选择子]]和段内偏移地址。
6. 加载到[[CS]]和[[EIP]]寄存器，跳转执行。
