# printf

`printf` 是C语言[[标准库libc]]中的一个核心函数，用于将格式化的[[数据]]输出到标准输出设备（通常是屏幕）。

## 核心功能
- **格式化输出**: `printf`最强大的功能是其格式化字符串。它允许程序员精确地控制输出的格式，包括数字的宽度、精度、对齐方式等。
- **类型转换**: 可以将各种[[数据]]类型（如整数、浮点数、字符、字符串）转换为人类可读的文本形式。

## 基本用法
```c
#include <stdio.h>

int main() {
    int age = 30;
    printf("My age is %d.\n", age);
    return 0;
}
```

- **格式字符串**: `"My age is %d.\n"` 是格式字符串，其中 `%d` 是一个**格式占位符**。
- **参数**: `age` 是要替换占位符的[[变量]]。
- `printf`会用`age`的值替换`%d`，最终输出 "My age is 30."。

## 常用格式占位符
- `%d` 或 `%i`: 有符号十进制整数。
- `%u`: 无符号十进制整数。
- `%f`: 浮点数。
- `%c`: 单个字符。
- `%s`: 字符串。
- `%x` 或 `%X`: 十六进制整数。
- `%p`: 指针地址。
- `%%`: 打印一个百分号`%`。

## 与printk的关系
- `printf` 是运行在[[用户空间]]的[[标准库libc]]函数，它最终依赖[[操作系统]]的[[系统调用]]（如`write`）来完成输出。
- [[printk]] 是[[Linux内核]]中的函数，它运行在[[内核空间]]，用于[[内核]]自身的[[日志]]和[[调试]]输出。
- 两者在用法上非常相似，但`printf`功能更全（如支持浮点数），而[[printk]]更轻量，且增加了日志级别功能。
