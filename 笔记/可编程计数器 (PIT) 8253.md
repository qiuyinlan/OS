# 可编程计数器 (PIT) 8253

**可编程间隔定时器 8253 (Programmable Interval Timer, PIT)** 是一块硬件芯片，用作可编程的定时/计数器。在PC体系结构中，它对于产生周期性的[[时钟中断]]至关重要。

## 核心作用
- **产生时钟中断**: `8253`的**计数器0**被专门用于产生一个周期性的硬件中断信号。这个信号的输出引脚(`OUT`)连接到[[可编程中断控制器 (PIC) 8259A]]的`IRQ0`引脚，从而成为系统中的[[时钟中断]]源。
- **定时刷新DRAM**: 计数器1用于DRAM刷新。
- **驱动扬声器**: 计数器2用于PC扬声器发出声响。

## 工作原理
- **分频**: `8253`接收一个 `1.19318MHz` 的固定高频输入时钟信号。它内部的减法计数器会根据预设的**计数初值**，对这个高频信号进行[[分频]]。
- **产生输出**: 当计数器从初值递减到0时，它会在`OUT`引脚上产生一个脉冲信号。如果工作在循环模式下（如方式2或方式3），计数器会自动重载初值，周而复始地产生脉冲信号，形成固定频率的[[时钟中断]]。

## 编程与控制
通过向`8253`的[[IO端口]]写入控制字和计数值来对其进行编程。

- **控制字寄存器 (端口 `0x43`)**:
    - 用于发送一个8位的控制字。
    - 控制字的内容指定了要操作的**计数器**（0, 1, 或 2）、**工作方式**（如方式2-比率发生器）、以及**读写模式**（如先读写低8位，再读写高8位）。

- **计数器端口**:
    - **计数器0**: 端口 `0x40`
    - **计数器1**: 端口 `0x41`
    - **计数器2**: 端口 `0x42`
    - 在写入控制字后，向相应的计数器端口写入16位的**计数初值**（分两次，先低8位后高8位）。

## 如何改变时钟中断频率
[[时钟中断]]的频率完全由写入计数器0的**计数初值**决定。

- **计算公式**:
  `中断频率 = 1,193,180 / 计数初值`

- **示例**:
  - 要想获得 `100Hz` 的中断频率。
  - `计数初值 = 1,193,180 / 100 ≈ 11932`。
  - 将 `11932` 这个16位数写入计数器0的端口`0x40`，即可将[[时钟中断]]频率设置为`100Hz`。
