# 函数 (Function)

在[[计算机]][[编程]]中，**函数**是一个组织好的、可重用的[[代码]]块，用于执行特定的[[任务 (Task)]]。它是[[程序]]模块化的基本单位。

## 核心特性
- **模块化**: 函数将复杂的[[程序]]分解为更小、更易于管理的部分。
- **可重用性**: 一旦定义，函数可以在[[程序]]的不同地方多次调用，避免[[代码]]重复。
- **输入与输出**:
    - 函数可以接受输入值，称为**参数**（或**实参**）。
    - 函数可以（可选地）返回一个输出值，称为**返回值**。

## 函数的组成
1.  **函数名**: 用于标识和调用函数的名称。
2.  **参数列表**: 函数接受的输入[[变量]]列表及其[[数据类型]]。
3.  **返回类型**: 函数执行完毕后返回值的[[数据类型]]。如果函数不返回任何值，则返回类型通常为`void`。
4.  **函数体**: 包含函数实际执行逻辑的[[代码]]块。

## 示例 (C语言)
```c
// 函数定义：接受两个整数参数，返回它们的和
int add(int a, int b) {
    int sum = a + b; // 函数体内的局部变量
    return sum;      // 返回计算结果
}

int main() {
    int x = 10, y = 20;
    int result = add(x, y); // 函数调用
    return 0;
}
```

## 应用场景
- **封装逻辑**: 将一组相关的操作封装在一个函数中。
- **[[抽象]]**: 隐藏复杂的实现细节，只暴露简单的接口。
- **[[回调函数]]**: 函数指针可以作为参数传递给其他函数，允许被调用的函数在特定时机“回调”传递进来的函数。
- **[[系统调用]]**: [[操作系统]]通过提供函数接口，让[[应用程序]]调用其内部服务。
