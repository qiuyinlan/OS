# dmesg (Diagnostic Messages)

`dmesg` 是[[Linux]]系统中一个非常重要的命令行工具，用于显示和管理[[Linux内核]]的**环形缓冲区**（Ring Buffer）中的诊断信息。

## 核心作用
- **查看内核日志**: `dmesg`命令允许用户查看[[Linux内核]]在启动过程和运行期间生成的所有消息。这些消息对于诊断[[硬件]]问题、驱动程序问题、[[系统崩溃]]原因以及理解[[内核]]行为至关重要。
- **故障排除**: 当系统出现问题（如[[硬件]]检测失败、驱动加载错误、[[USB]]设备连接异常）时，`dmesg`是第一个被检查的工具之一。

## 消息来源
- `dmesg`命令读取的信息直接来源于[[Linux内核]]维护的**环形缓冲区**。这是一个固定大小的[[内存]]区域，[[内核]]将`printk`函数输出的所有消息写入其中。当缓冲区满时，新的消息会覆盖最旧的消息。

## 典型用途
1.  **查看启动信息**: 系统启动时，屏幕上的消息会快速滚过。使用`dmesg`可以详细回顾启动过程中[[内核]]检测到的所有[[硬件]]、加载的驱动程序等信息。
    ```bash
    dmesg | less   # 分页查看所有消息
    ```
2.  **筛选消息**: 可以结合`grep`或其他工具来筛选特定类型的消息。
    ```bash
    dmesg | grep -i usb   # 查看所有与USB相关的内核消息
    ```
3.  **实时跟踪**: 使用`dmesg --follow`可以实时查看新的[[内核]]消息。
4.  **时间戳**: `dmesg -T`可以显示可读的时间戳，方便事件关联。

## 与syslog的关系
- 虽然`dmesg`直接访问[[内核]]的环形缓冲区，但这些[[内核]]消息通常也会被`syslog`守护[[进程 (Process)]]捕获，并写入`/var/log/kern.log`或`/var/log/messages`等常规日志文件。
- `dmesg`的优势在于它提供了对原始[[内核]]日志的直接、实时访问，不依赖于任何[[用户空间]]守护进程。
