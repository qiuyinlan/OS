# write系统调用

`write` 是[[类Unix操作系统|UNIX-like]]系统中一个基本的[[系统调用]]，用于将[[数据]]从[[应用程序]]的缓冲区写入到一个打开的[[文件]]中。

## POSIX标准定义
```c
ssize_t write(int fd, const void *buf, size_t count);
```
- **`fd` (File Descriptor)**: [[文件描述符]]。一个非负整数，用于唯一标识一个已打开的[[文件]]。特殊值如`0`代表标准输入（stdin），`1`代表标准输出（stdout），`2`代表标准错误（stderr）。
- **`buf` (Buffer)**: 指向要写入[[数据]]的[[内存]]缓冲区的指针。
- **`count`**: 要写入的字节数。

## 返回值
- **成功**: 返回实际写入的字节数。这个值可能小于`count`，例如当[[硬盘]]空间不足时。
- **失败**: 返回`-1`，并设置全局[[变量]]`errno`以表明错误原因。

## 工作流程
1.  **用户态**: [[应用程序]]调用`write`函数。
2.  **陷入内核**: `write`函数通过[[软件]][[中断]]（如`int 0x80`）触发一个[[系统调用]]，使[[中央处理器 (CPU)]]从[[用户空间]]切换到[[内核空间]]。
3.  **内核态**:
    -   [[内核]]根据[[系统调用号]]在[[syscall_table|系统调用表]]中找到`sys_write`函数。
    -   `sys_write`函数根据传入的[[文件描述符]]`fd`，在当前[[进程 (Process)]]的[[文件描述符]]表中找到对应的[[文件]]结构。
    -   [[内核]]执行[[文件系统]]的写入操作，将[[数据]]从用户提供的`buf`缓冲区复制到[[内核]]缓冲区，并最终写入到[[硬盘]]等物理设备。
4.  **返回用户态**: 操作完成后，[[内核]]将结果（实际写入的字节数或错误码）返回给[[应用程序]]。

## 与`printf`的关系
- `printf`是C[[标准库libc]]中的一个高级函数。
- `printf`在内部会格式化字符串，并将最终结果通过调用`write`[[系统调用]]（通常是向标准输出，即`fd=1`）来输出到屏幕。
