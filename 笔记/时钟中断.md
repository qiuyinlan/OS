# 时钟中断

**时钟中断**是由硬件定时器（[[可编程计数器 (PIT) 8253]]）周期性产生的一种[[外部中断]]。它是现代[[操作系统]]实现多任务[[进程调度|调度]]的脉搏。

## 作用
- **时间片轮转**: [[时钟中断]]是实现[[时间片]]轮转调度的基础。每次[[时钟中断]]发生时，[[操作系统]]都有机会：
    1.  将当前运行任务的`ticks`（剩余时间片）减1。
    2.  检查当前任务的`ticks`是否已耗尽。
    3.  如果时间片耗尽，就调用[[进程调度|调度器]]（`schedule()`），切换到下一个任务。
- **系统计时**: 内核可以累加[[时钟中断]]的发生次数（`ticks`），从而得到一个系统运行时间的基准。
- **执行周期性任务**: [[操作系统]]可以利用[[时钟中断]]来执行需要周期性运行的任务。

## 实现机制
1.  **硬件定时器**: [[可编程计数器 (PIT) 8253]]的[[计数器0]]被配置为一个比率发生器（模式2）。
2.  **产生信号**: `8253`对一个`1.19318MHz`的输入时钟进行[[分频]]。当计数值减到0时，它会通过`OUT`引脚发出一个电信号。
3.  **连接到PIC**: 这个`OUT`信号连接到[[可编程中断控制器 (PIC) 8259A]]的`IRQ0`引脚上。
4.  **触发中断**: [[可编程中断控制器 (PIC) 8259A|8259A]]接收到`IRQ0`信号后，向[[中央处理器 (CPU)]]发送一个[[中断]]请求。
5.  **执行处理程序**: [[中央处理器 (CPU)]]响应中断，执行注册在[[中断向量号]]`0x20`（我们设定的`IRQ0`对应的向量号）上的[[中断处理程序]] `intr_timer_handler`。

## 调整频率
[[时钟中断]]的频率可以通过编程`8253`的[[计数初值]]来改变。
- **公式**: `中断频率 = 1,193,180 / 计数初值`
- **示例**: 为了获得`100Hz`的中断频率（即每10ms一次中断），需要设置的[[计数初值]]为`11932`。
