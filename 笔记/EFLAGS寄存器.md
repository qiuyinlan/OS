# EFLAGS寄存器

**EFLAGS** 是x86架构中的一个核心**状态和控制[[寄存器]]**。它是一个32位的[[寄存器]]，其中的每一个位（称为**标志位**）都具有特殊的含义，用于记录[[中央处理器 (CPU)]]的当前状态或控制其行为。

在64位架构中，这个[[寄存器]]扩展为64位，称为**RFLAGS**。

## 主要作用
- **记录运算结果**: 许多算术和逻辑[[指令]]会根据其执行结果自动设置或清除EFLAGS中的某些标志位。
- **控制程序流程**: 条件跳转[[指令]]（如 `jz`, `jc`）会检查这些标志位，以决定[[程序]]的执行路径。
- **控制[[中央处理器 (CPU)]]行为**: 一些标志位可以直接控制[[中央处理器 (CPU)]]的某些行为，例如是否响应[[中断]]。

## 主要标志位分类

### 1. 状态标志 (Status Flags)
这些标志位由[[中央处理器 (CPU)]]根据算术运算的结果自动设置。

- **CF (Carry Flag - 进位标志)**: 无符号数运算发生溢出时置1。用于多精度运算。
- **PF (Parity Flag - 奇偶标志)**: 结果中最低有效字节的位为1的个数为偶数时置1。
- **AF (Auxiliary Carry Flag - 辅助进位标志)**: 用于BCD码运算。
- **ZF (Zero Flag - 零标志)**: 运算结果为0时置1。是判断“相等”的常用依据。
- **SF (Sign Flag - 符号标志)**: 运算结果为负数时（最高位为1）置1。
- **OF (Overflow Flag - 溢出标志)**: **有符号数**运算发生溢出时置1。

### 2. 控制标志 (Control Flags)
只有一个，由程序设置，用于控制字符串[[指令]]的方向。

- **DF (Direction Flag - 方向标志)**:
    - `DF = 0`: 字符串操作从低地址向高地址进行。
    - `DF = 1`: 字符串操作从高地址向低地址进行。

### 3. 系统标志 (System Flags)
这些标志位控制着系统的操作模式，通常由[[操作系统]]内核修改，用于管理任务和[[特权级]]。

- **IF (Interrupt Enable Flag - 中断允许标志)**:
    - `IF = 1`: [[中央处理器 (CPU)]]可以响应外部的[[可屏蔽中断]]。
    - `IF = 0`: [[中央处理器 (CPU)]]忽略外部的[[可屏蔽中断]]。
- **TF (Trap Flag - 陷阱标志)**: `TF = 1`时，[[中央处理器 (CPU)]]进入单步执行模式，每执行一条[[指令]]就产生一个[[Debug异常|调试异常]]，用于[[调试]]。
- **IOPL (I/O Privilege Level - I/O特权级)**: 标记了当前任务执行I/O[[指令]]所需要的[[特权级]]。
- **NT (Nested Task Flag - 嵌套任务标志)**: 用于控制[[中断]]任务的返回。
- **RF (Resume Flag - 恢复标志)**: 用于配合[[调试]][[寄存器]]，控制是否在[[指令]]断点后再次产生[[调试]]异常。
- **VM (Virtual 8086 Mode Flag - 虚拟8086模式标志)**: `VM = 1`时，[[中央处理器 (CPU)]]进入虚拟8086模式，用于在[[保护模式]]下模拟[[实模式]]环境。
