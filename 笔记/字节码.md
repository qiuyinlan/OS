# 字节码 (Bytecode)

**字节码**是一种中间[[代码]]表示形式，它介于人类可读的[[高级语言]][[源码]]和机器可直接执行的[[机器语言]]之间。它通常被设计为由**[[虚拟机]]**（Virtual Machine, VM）或解释器高效执行。

## 核心目的
- **平台独立性**: 字节码的主要优势是实现了“一次编写，到处运行”（Write Once, Run Anywhere）。[[源码]]被编译成字节码后，可以在任何安装了兼容[[虚拟机]]的平台上运行，而无需为每个平台重新编译成特定的[[机器语言]]。
- **提高安全性**: 字节码可以在[[虚拟机]]的沙箱环境中运行，限制了程序对底层系统资源的访问，从而增强了安全性。
- **优化**: 字节码通常比[[源码]]更紧凑、更优化，有助于提高解释器的执行效率。

## 工作流程
1.  **编译到字节码**: [[高级语言]][[源码]]（如Java、Python）首先由[[编译器]]编译成字节码。
2.  **[[虚拟机]]执行**: 生成的字节码不能直接由[[中央处理器 (CPU)]]执行。它需要由一个[[虚拟机]]（如Java的JVM、Python解释器）或解释器来执行。[[虚拟机]]会将字节码翻译成[[机器语言]]，然后由[[中央处理器 (CPU)]]执行。
3.  **JIT编译**: 为了提高执行效率，许多[[虚拟机]]会使用即时编译（Just-In-Time, JIT）技术。JIT编译器在运行时将部分或全部字节码编译成本地[[机器语言]]，从而显著加速执行。

## 字节码与相关概念的对比
- **与[[源码]]**: [[源码]]是人类可读的[[高级语言]][[代码]]，字节码是编译后的、更抽象、更紧凑的数字形式。
- **与[[机器语言]]**: [[机器语言]]是[[中央处理器 (CPU)]]直接执行的最低级二进制[[指令]]，是与特定[[中央处理器 (CPU)]]架构相关的。字节码是平台独立的中间[[代码]]，需要[[虚拟机]]来翻译成[[机器语言]]。

## 常见使用字节码的语言
- **Java**: Java[[源码]]编译成Java字节码（`.class`文件），由Java[[虚拟机]]（JVM）执行。
- **Python**: Python[[源码]]编译成字节码（`.pyc`文件），由Python解释器执行。
- **.NET语言 (C#)**: 编译成通用中间语言（CIL），由公共语言运行时（CLR）执行。
